## 🚀 项目简介

**DevToolbox** 是一个前端导航工具，将你日常高频访问的站点整理成一张“会呼吸的工作台”。它采用**暗色沉浸式**设计，背景带有动态粒子、极光光晕和可交互的卡片效果，所有数据仅保存在浏览器本地，无需服务器，双击 `index.html` 即可运行。

本项目由真实收藏夹文件（`favorites_2026_9_8.html`）整理而来，涵盖 **信息查询、AI工具、视频影音、办公通讯、云存储、在线工具箱、编程技术、地图出行、视频解析、素材资源、独立工具、小说阅读、手机应用** 等 **13 个分类**，共 **90+** 个精选站点。

## ✨ 功能特性

- **🔐 本地登录保护**  
  通过简单的本地加密验证保护隐私，首次使用需输入预设密码解锁，所有凭证仅保存在你的浏览器中。

- **🎨 沉浸视觉体验**  
  - 动态粒子背景，鼠标移动可扰动粒子轨迹  
  - 缓慢漂移的极光光晕，营造深邃氛围  
  - 跟随光标的柔光效果（桌面端）  
  - 卡片悬停有光晕和微倾斜 3D 动效（桌面端）

- **🔍 智能搜索**  
  - 实时过滤站点（按名称、描述、关键词、域名）  
  - 回车即搜：若唯一匹配则直接打开该站点，否则调用搜索引擎（Bing/百度/Google 可切换）  
  - 快捷键支持：`/` 聚焦搜索，`Esc` 清空搜索

- **📂 分类导航**  
  - 横向滚动胶囊栏，点击切换分类  
  - 每个分类显示站点数量，选中高亮并滚动到可视区域

- **📊 数据统计**  
  实时显示精选站点总数、分类数量，数字带有滚动动画

- **📋 一键复制**  
  每个站点卡片都提供复制链接按钮，点击即复制，并显示成功提示

- **🛡️ 安全防护**  
  内置常规的防误触措施，保障页面不被意外干扰

- **📱 响应式设计**  
  完美适配平板与手机，移动端优化触控交互，自动隐藏部分装饰元素

- **🌙 暗色沉浸**  
  全程暗色调，减轻视觉疲劳，配合渐变文字与玻璃态质感

## 🧰 技术栈

- **HTML5** + **CSS3**（自定义属性、Grid、Flex、动画、渐变、滤镜）
- **原生 JavaScript**（ES6+，无任何第三方库或框架）

- **localStorage**（用户设置、登录令牌、站点映射）

## 🏃 快速开始

### 运行方式

直接将项目克隆或下载到本地，用浏览器打开 `index.html` 即可，无需任何构建工具或服务器。

```bash
git clone https://github.com/your-username/devtoolbox.git
cd devtoolbox
# 双击 index.html 或使用 Live Server 等扩展
```

### 登录验证

首次打开页面会显示登录遮罩，需要输入密码才能解锁工具箱。密码在项目初始化时已预设，且通过本地哈希加密存储。登录成功后，令牌会保存在 localStorage，下次打开自动跳过登录。

> 💡 若需重置密码或清除登录状态，可在浏览器开发者工具中执行：
> ```js
> localStorage.removeItem('dtb_auth');
> localStorage.removeItem('dtb_pw_hash');
> ```
> 或直接清除站点所有本地数据。

## 📊 数据说明

站点数据定义在 `js/data.js` 中，包含分类（`CATEGORIES`）和站点列表（`SITES`）。

### 分类结构

```js
const CATEGORIES = [
  {
    id: 'search',          // 唯一标识
    name: '信息查询',       // 显示名称
    color: '#38bdf8',      // 主题色（用于卡片高亮和图标）
    icon: '<svg>...</svg>' // SVG 图标路径（仅内部路径部分）
  },
  // ...
];
```

### 站点结构

```js
const SITES = [
  {
    name: '手机号段网',          // 站点简称
    desc: '手机号段信息查询平台', // 简短描述（卡片显示）
    url: 'https://telphone.cn/', // 完整网址
    cat: 'search',               // 所属分类 id
    kw: '手机 号码 归属地 运营商' // 搜索辅助关键词
  },
  // ...
];
```

## ✏️ 自定义扩展

你可以轻松添加新的分类或站点，无需修改核心逻辑。

### 添加分类

在 `CATEGORIES` 数组中新增一个对象，确保 `id` 唯一，并参考现有配色选取 `color` 和 `icon`（SVG 路径）。

### 添加站点

在 `SITES` 数组末尾新增对象，填入所需字段。注意 `cat` 必须匹配已有的分类 `id`。`kw` 用于增强搜索匹配，可填写同义词或关联词。

> 💡 **提示**：添加后刷新页面，统计数字和分类计数将自动更新。
